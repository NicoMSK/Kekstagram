# Kekstagram (React + TypeScript) Учебный проект

Веб-приложение по типу социальной сети, разрабатываемое на React и TypeScript. В процессе разработки работаю с состоянием компонентов, setState и React Hooks, реализую логику пользовательского интерфейса и взаимодействие между компонентами.

## Стек

- React
- TypeScript
- Vite
