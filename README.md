<h1>Приложение Kekstagram</h>

<h2>Описание</h2>
<p>Учебный проект в формате мини-социальной сети, созданный для практики React и TypeScript. Реализована работа с компонентами, состоянием и пользовательскими событиями с использованием React Hooks. Проект собран с помощью Vite для быстрой разработки.</p>

<h3>Технологии:</h3>
React, TypeScript, Vite

<h3>Как запустить</h3>
<p>Проект можно запустить по <a href="https://nicomsk.github.io/Kekstagram/">этой ссылке.</a> </p>
